## 与 flash 原模板的差异（云端适配）
- 原模板为 Mac + Remotion/TSX 工程；本机无该工程与 Node 渲染链，改为 Python/PIL + numpy 逐帧渲染 → ffmpeg 管道，九幕结构、时间轴预算、Chrome 三层、色彩纪律照原 skill 执行。
- 字体改用 Noto Serif CJK SC / Noto Sans CJK SC（本机无思源宋体独立字族），字号按 3:4 母版重标。
- 音频用 `mmx speech synthesize --voice male-qn-jingying-jingpin`，配乐为 numpy 程序化合成（无外部曲库）。

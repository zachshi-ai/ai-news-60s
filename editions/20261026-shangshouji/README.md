# 上手记 · 一周一件事

「AI 快讯 60 秒」同一条流水线的第二个栏目：不播新闻，只教一件事——一周一件事，周一到周四一天拆一步，零基础照着做就行。

## 形态

- 9 句旁白，60 秒，3:4 竖屏
- 结构固定：钩子 → 为什么要做 → 交付物长什么样 → 边界（它不替你做判断）→ 四步总览 → 第 1 步细讲 → 第 3 步细讲（最容易翻车的一步）→ 验收动作 → 收尾预告
- 每周只讲一个主题，四步拆到能直接照做

## 与快讯的差别

| | 快讯 60 秒 | 上手记 |
|---|---|---|
| 选题 | 当天新闻 | 一个可复用的工作方法 |
| 篇幅分配 | 发布/跑分/价格占一半 | 实操占七成以上 |
| 收尾 | 信源 + CTA | 明天拆第几步 |

## 本期样例（2026.10.26）

主题：把三十页报告压成一张三列对比表。

- `vo-lines.txt`：9 句旁白
- 四步：定列（先定列再上传）→ 上传 → 要表（只输出表格，一行一家，列名和单位写死）→ 抽查（抽两格回原文核对）
- 强调的边界：它替你把数找出来、把口径拉平、排成一行一家，但不替你做判断

渲染与混音复用 `pipeline/` 下同一套脚本。

## 工程结构
```
scripts/vo-lines.txt     9 句旁白（TTS 实测总长 44.20s ≤ 48s）
scripts/make-vo.sh       mmx 逐句 TTS → 剪首尾静音 → 时长表

scripts/render.py        九幕渲染（PIL+numpy）→ rawvideo → video-only.mp4
scripts/make-cover.py    发布封面 1080×1440
```

## 工程结构
```
scripts/vo-lines.txt     9 句旁白（TTS 实测总长 43.58s ≤ 48s）
scripts/make-vo.sh       mmx 逐句 TTS → 剪首尾静音 → 时长表
scripts/make-audio.py    120BPM 程序化配乐 + VO + ducking → out/audio.wav
scripts/render.py        九幕渲染（PIL+numpy）→ rawvideo → video-only.mp4
scripts/make-cover.py    发布封面 1080×1440
```

视觉语言：作业手册（暖灰纸底 #F3F1EB + 墨黑 #1A1A1A + 蓝图蓝 #1E56B4 骨架 + 安全橙 #CD5224 强调 + 批改红 #B03028）；全片颗粒/扫描线/暗角；色差大字只在钩子幕衰减；白闪对齐 VO 起点（帧 5）。
